# Скрипты, методы решения и вспомогательные утилиты

В этой папке собраны алгоритмы, вспомогательные утилиты и математические верификаторы для различных типов задач Решу ЕГЭ / ОГЭ / ВПР.

## Структура скриптов:

### 1. Парсинг и инспекция DOM / заданий
- `dump_full_problems.py` — извлечение условий задач с формулами (alt-текст тегов `<img>`) и скачивание иллюстраций.
- `inspect_c_parts.py` — инспекция структуры развёрнутых ответов (Часть 2 / задания C).
- `inspect_tasks.py` — быстрая проверка полей ввода в открытом варианте.
- `parse_page.py` — извлечение полей и текста со страниц Решу ЕГЭ.
- `dump_detailed.py` — расширенный дампер дерева DOM.

### 2. Математические верификаторы и методы решения (Профильная математика)
- `solve_task3_curve.py`, `analyze_task3.py` — численный анализ векторных кривых Безье (SVG) для определения промежутков возрастания/убывания и корней производной $f'(x)$.
- `verify_task8.py` — верификатор корней тригонометрических уравнений на отрезке и проверка ОДЗ.
- `verify_task9.py` — верификатор логарифмических неравенств и границ интервалов.
- `verify_task10.py` — оптимизационные задачи по экономике/производству (поиск оптимума добычи металлов и сплавов).
- `solve_task11.py` — анализ систем с параметром (пересечение квадрата и окружности, количество корней).
- `solve_task12.py` — теория чисел, делимость, переборные и экстремальные оценки процентов учащихся.

### 3. Информатика
- `solve_task3.py` — задачи на базы данных и поиск связей.
- `solve_task9.py` — анализ числовых таблиц и условий делимости/повторяемости.
- `solve_task18.py` — динамическое программирование (робот на числовом поле с препятствиями/монетами).
- `solve_task22.py` — параллельные процессы и время выполнения зависимых задач.
