Комплексный инструмент автоматизации для образовательного портала **СДАМ ГИА** ([Решу ЕГЭ](https://ege.sdamgia.ru/), [ОГЭ](https://oge.sdamgia.ru/), [ВПР](https://vpr.sdamgia.ru/)): выгрузка вариантов, парсинг задач с сохранением формул и графиков, интеллектуальное заполнение ответов, накрутка времени решения (эмуляция присутствия ученика) и безопасная отправка результатов с фотофиксацией.

---

## 🌟 Основные возможности

- 🔑 **Авторизация в 1 клик:** встроенная утилита `scripts/save_session_cookies.py` открывает окно браузера, ждёт вашего входа на сайт и автоматически экспортирует `cookies.json`.
- 🛡️ **Защита от смены варианта:**
  - Автоматически нажимает кнопку **«Продолжить решение»** при наличии индивидуального варианта от учителя (вместо сброса теста).
  - Сверяет ID и номера всех задач страницы с выгруженными данными перед отправкой (`verify_variant_match`). При малейшем несовпадении отправка блокируется во избежание сдачи чужого/нового варианта.
- ⏳ **Человекоподобная накрутка времени (`--delay`):**
  - Поддержка случайных интервалов (например, `--delay 20-40` минут или `--delay 30-60s`).
  - Окно браузера остаётся открытым на странице теста на время отсчёта, в консоли отображается обратный таймер.
- 📝 **Поддержка любых форматов ответов:**
  - **Часть 1:** одиночные поля, числа с запятой (`0,6`), текстовые строки.
  - **Составные поля:** задачи с несколькими полями ввода (таблицы, координаты, перечисления).
  - **Часть 2 (Развёрнутые ответы):** заполнение редакторов Draft.js (React), MathQuill/HTML-редакторов и фоновое сохранение через AJAX `/sol_upload`.
- 📸 **Двойное скриншотирование:**
  - `screenshots/before_submission.png` — снимок всей страницы с заполненными ответами ДО нажатия отправки.
  - `screenshots/submission_result.png` — снимок экрана подтверждения сдачи теста ПОСЛЕ отправки.
- 📦 **Пакетный запуск (`batch_runner.py`):** параллельная или последовательная сдача нескольких тестов с индивидуальными таймерами для каждого варианта.
- 🤖 **AI-Ready (`AI_GUIDE.md`):** готовый регламент и формат данных для взаимодействия с языковыми моделями (Gemini, Claude, GPT, DeepSeek).

## 🚀 Быстрый старт

### 1. Клонирование и установка зависимостей

Требуется **Python 3.10+**.

```bash
git clone https://github.com/shecterkashreka/sdamgia-auto-solver.git
cd sdamgia-auto-solver

# Установка библиотек
pip install -r requirements.txt

# Установка браузеров Playwright
playwright install chromium
# (Опционально для Edge на Windows: playwright install msedge)
```

### 2. Авторизация (получение cookies)

Запустите интерактивный скрипт сохранения куки:

```bash
python scripts/save_session_cookies.py
```

Откроется окно браузера. Войдите в свой аккаунт на сайте Решу ЕГЭ / СДАМ ГИА. Скрипт зафиксирует авторизацию и автоматически сохранит `cookies.json` в корневой папке.

*(Альтернативно: скопируйте значения кук `atoken` и `rtoken` из DevTools браузера в файл `cookies.json` по образцу `cookies.example.json`).*

## 📖 Пошаговое использование

### Шаг 1. Выгрузка заданий варианта (Trial Run)

Запустите скрипт в пробном режиме без отправки:

```bash
python run_session.py --url "https://math-ege.sdamgia.ru/test?id=12345678" --trial
```

Скрипт:
1. Запустит браузер под вашей сессией;
2. Обработает окно «Продолжить решение» (при наличии);
3. Извлечёт все задачи и сохранит их в:
   - `tasks.txt` — человекочитаемый текст с номерами, ID и полями ввода;
   - `tasks.json` — структурированные JSON-данные.

### Шаг 2. Подготовка ответов (`answers.json`)

Создайте или отредактируйте файл `answers.json` в корне проекта или в папке теста:

```json
{
  "1": "14",
  "2": "0,75",
  "3": ["4", "18200"],
  "12": "ОДЗ: x > 0, x != 1.\nПреобразуем: log2(x) = t => t² - 3t + 2 = 0.\nКорни: t1 = 1, t2 = 2.\nОбратная замена: x = 2 или x = 4.\nОтвет: 2; 4"
}
```

#### Правила формата `answers.json`:
- **По номеру задания:** `"1": "42"` — заполняет первое поле задачи №1.
- **По имени DOM-поля:** `"answer_1_952943": "42"` — точное заполнение конкретного поля.
- **Составные поля:** `"3": ["4", "18200"]` — массив строк заполнит поля подномеров по порядку.
- **Развёрнутые ответы:** текст передаётся обычной строкой (символы переноса строк `\n` автоматически конвертируются в параграфы для визуального редактора Решу ЕГЭ).

### Шаг 3. Запуск и отправка с накруткой времени

```bash
python run_session.py --url "https://math-ege.sdamgia.ru/test?id=12345678" --auto-submit --delay 20-40
```

- `--auto-submit` — автоматически отправляет форму после выдержки таймера.
- `--delay 20-40` — скрипт выберет случайное время от 20 до 40 минут, оставит браузер открытым на странице и отправит работу по окончании времени.
- В процессе работы будут сделаны скриншоты в папку `screenshots/`.

## ⚡ Пакетная обработка нескольких тестов (`batch_runner.py`)

Если вам нужно решить несколько тестов одновременно:

### 1. Выгрузка всех тестов:
```bash
python batch_runner.py https://math-ege.sdamgia.ru/test?id=11111111 https://inf-ege.sdamgia.ru/test?id=22222222 --trial
```
Задания сохранятся по изолированным папкам `tests/11111111/` и `tests/22222222/`.

### 2. Заполнение ответов:
Заполните `tests/11111111/answers.json` и `tests/22222222/answers.json`.

### 3. Параллельная отправка с индивидуальными таймерами:
```bash
python batch_runner.py https://math-ege.sdamgia.ru/test?id=11111111 https://inf-ege.sdamgia.ru/test?id=22222222 --auto-submit --delay 25-45
```
Каждый тест будет запущен в отдельном процессе со своим независимым случайным таймером.

## ⚙️ Справка по аргументам CLI

### `run_session.py`

| Параметр | Тип | Описание |
|---|---|---|
| `--url` | `str` | **(Обязательно)** Ссылка на тест СДАМ ГИА / Решу ЕГЭ |
| `--trial` | `flag` | Пробный запуск: выгрузка задач и проверка DOM без заполнения и отправки |
| `--auto-submit` | `flag` | Автоматическая отправка работы после заполнения ответов и ожидания таймера |
| `--answers` | `str` | Путь к кастомному файлу ответов (по умолчанию `answers.json`) |
| `--test-dir` | `str` | Папка для изоляции артефактов конкретного теста |
| `--delay` | `str` | Диапазон случайной задержки: `'20-40'` (минуты), `'15-30s'` (секунды), `'1-2h'` |
| `--delay-min` | `int` | Минимальная задержка в минутах |
| `--delay-max` | `int` | Максимальная задержка в минутах |
| `--headless` | `flag` | Фоновый запуск без отображения графического окна браузера |
| `--no-clean-cache`| `flag` | Отключить автоматическую очистку кэша после завершения работы |
